## Assistant

**같은 계정으로 로그인하는 것과, 다른 컴퓨터의 로컬 작업 기록을 연결하는 것은 별개입니다.** 현재 이 채팅에서 접근 가능한 컴퓨터도 `Local` 하나뿐이라, 다른 컴퓨터가 연결된 상태는 아닙니다.

원하시는 방식에 따라 방법이 달라요.

- **진행 중인 동일한 작업과 대화를 두 컴퓨터에서 보고 싶다면:** 작업 중인 컴퓨터에 원격으로 접속하는 방식이 필요합니다. Codex의 컴퓨터 간 연결 기능이 제공되는지는 양쪽 앱의 **설정 → Connections(연결)**에서 확인해야 합니다. 공식 문서에서는 모바일에서 연결된 컴퓨터의 작업을 보고 이어가는 **Remote** 기능은 확인되지만, 데스크톱 두 대 사이의 구체적인 연결 절차는 확인되지 않았습니다. [공식 Remote 안내](https://developers.openai.com/blog/mastering-codex-remote-for-engineering)
- **코드만 두 컴퓨터에서 이어서 작업하려면:** Git 저장소에 push/pull하면 됩니다. 다만 **Codex 대화 기록은 함께 옮겨지지 않습니다.**
- **당장 같은 화면을 보려면:** 작업 중인 컴퓨터에 원격 데스크톱으로 접속하는 방법을 사용할 수 있습니다.

다른 컴퓨터도 Windows인가요? 그리고 양쪽 Codex 설정에 **Connections 또는 Remote** 메뉴가 보이나요? 그에 맞춰 연결 방법을 좁혀 안내해 드릴게요.
